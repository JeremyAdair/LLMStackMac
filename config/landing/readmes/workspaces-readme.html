This page now documents the canonical PDF ingestion path:

  • data/pdfs/ for incoming PDFs
  • data/pdfs/processed/ for converted markdown and successful ingest outputs
  • data/pdfs/failed/ for failed ingest files

Conversion job: docker compose --env-file .env.mac -p llm-lab -f compose/lab.yml run --rm pdf-ingest

Indexing job: docker compose --env-file .env.mac -p llm-lab -f compose/lab.yml run --rm rag-pipeline
