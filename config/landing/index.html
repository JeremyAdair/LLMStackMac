What Each Service Is For

  • Authelia Login: Sign in to access protected apps.
  • Open WebUI: Main chat interface for local LLM use.
  • Flowise: Build visual AI flows, tools, and RAG chains.
  • Node-RED: Low-code automations and workflow orchestration.
  • Grafana: Metrics dashboards for service health.
  • OpenHands: Agentic coding workspace and task runner.
  • Qdrant Dashboard: Inspect collections and vector data.
  • Prometheus UI: Query raw metrics and targets.
  • pgAdmin: Manage Postgres databases and queries.
  • RedisInsight: Inspect Redis keys, memory, and commands.
  • Forgejo: Self-hosted Git repos and code collaboration.
  • Python Scripts API: Run toolbox scripts and helper endpoints.
  • Docs: Runbooks, setup notes, and troubleshooting.
